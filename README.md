🕹️ Pac-Man Tech Pro - Cyber Edition
🚀 Sobre o Projeto
O Pac-Man Tech Pro reinventa o clássico arcade dos anos 80 em um ambiente cibernético e futurista. Com efeitos de neon, painéis estilizados e áudio dinâmico gerado em tempo real via Web Audio API, o jogo oferece uma experiência imersiva diretamente no navegador, sem necessidade de instalações ou plugins.
✨ Principais Funcionalidades
￼ Tema Cyberpunk/Tech: Labirinto estilizado com nós de dados (⁠Data Nodes⁠), firewalls inteligentes e escudos de energia.
￼ Inteligência Artificial dos Fantasmas: Os 4 inimigos possuem comportamentos dinâmicos de patrulha, perseguição e vulnerabilidade.
￼ Áudio Nativo (Web Audio API): Efeitos sonoros retrô gerados proceduralmente (comer pastilhas, energizantes, captura de fantasmas e game over).
￼ Controles Adaptáveis:
￼ 🖥️ Desktop: Teclado (⁠WASD⁠ ou Setas) + Atalho de Pausa (⁠ESC⁠).
￼ 📱 Mobile / Touch: D-Pad virtual otimizado na tela para jogabilidade fluida em smartphones e tablets.
￼ Persistência de Recordes (⁠localStorage⁠): O seu recorde de pontuação (⁠High Score⁠) fica salvo automaticamente no navegador.
￼ Arquivo Único (Single-File): Todo o código (HTML, CSS e JavaScript) está condensado em um único arquivo, facilitando imensamente a hospedagem.
🎮 Como Jogar
1. Acesse o jogo publicado ou abra o arquivo ⁠index.html⁠ em qualquer navegador moderno.
2. Clique no botão "INICIALIZAR SISTEMA".
3. Objetivo: Colete todos os nós de dados azuis espalhados pelo grid cibernético.
4. Super Boosters: Colete as esferas maiores piscantes para hackear os firewalls (fantasmas), permitindo capturá-los para ganhar pontos extras.
5. Vidas: Você possui 3 tentativas antes que ocorra uma falha crítica de segurança (Game Over).
🛠️ Tecnologias Utilizadas
￼ HTML5 Canvas: Para renderização gráfica em alta performance a 60 FPS.
￼ Tailwind CSS: Para estilização da interface e layout responsivo.
￼ Google Fonts: Fontes customizadas (⁠Press Start 2P⁠ e ⁠Inter⁠).
￼ JavaScript (Vanilla): Lógica do jogo, máquina de estados e IA sem dependências externas.
🌐 Como Hospedar Gratuitamente
Quer colocar o jogo online para compartilhar com seus amigos? Siga um dos métodos abaixo:
Opção 1: Netlify Drop (Mais rápido - Menos de 30 segundos)
1. Acesse drop.netlify.com.
2. Renomeie o arquivo do seu jogo para ⁠index.html⁠.
3. Arraste e solte o arquivo na área pontilhada da página.
4. Pronto! O Netlify gerará um link instantâneo para você testar no celular.
Opção 2: GitHub Pages
1. Crie um repositório público no GitHub.
2. Faça o upload do arquivo renomeado como ⁠index.html⁠.
3. Vá em Settings > Pages, selecione a branch ⁠main⁠ e salve. O seu link oficial estará disponível em instantes!
